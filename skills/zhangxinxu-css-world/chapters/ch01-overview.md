# Chapter 1: 概述

## Core Idea
CSS 世界特指 CSS2.1 的世界，它为"图文信息展示"而生，其统治性机制是"流"——理解 CSS 属性要看特性间的相互联系与具象能力，而不是逻辑推理。

## Frameworks Introduced
- **CSS 世界观（拟人化体系）**：把 CSS 当成有血有肉的个体来理解。
  - HTML 标签 = 魔法石；选择器 = 选择法器；CSS 属性 = 魔法师；属性值 = 魔法技能；浏览器 = 王国；操作系统 = 平行世界；版本升级 = 法律法规更新。
  - When to use: 学习/记忆陌生属性时，把它放进"个体+关系"的体系里，而不是背属性值。
- **流（flow）**：CSS 世界中引导元素排列和定位的一条看不见的"水流"，一种基本定位与布局机制，类比现实世界的水流物理规则。
  - `<div>` 是水（块级），`<span>` 是浮木（内联）——HTML 默认表现符合"流"，所以整个 CSS 世界被"流"统治（擒贼先擒王）。
  - 特殊布局 = 破坏"流"来实现的，本质上还是在和"流"打交道。
  - "文档流从左往右自上而下"的说法不严谨——流向是可以改变的（见 ch12）。
- **流体布局**：利用元素"流"的特性实现的各类布局效果。
  - 因"流"自带自适应特性，流体布局通常自适应；但"流体布局" ⊂ "自适应布局"（table 布局可自适应但不属于流体布局）。
  - 风靡的"div+CSS 布局"实质就是流体布局。

## Key Concepts
- **层叠（cascade）**：样式可以层层累加——CSS 当年胜出其他样式表语言靠的就是这个特性（Cascading Style Sheets 得名于此）。
- **具象能力**：CSS 学习看重特性间联系与具象思维，无逻辑可言，所以 C++/Java 程序员学 CSS 常常"只得其形、不得其髓"。
- **CSS 世界的边界**：本书"世界"= CSS2.1，全面支持从 IE8 开始；`<table>` 有自己的世界，"流"对它不适用（单元格 vertical-align 表现也不同）。
- **CSS3 = 新世界**：flex/grid、圆角阴影渐变、transform、filter、animation 等，为复杂网页而生，与"流"关系不大，不在本书范围。

## Mental Models
- 用"造物主视角"审题：遇到费解的表现，问"如果我为图文展示设计这个世界，为什么会这样设计？"——CSS 世界的诞生就是为图文信息展示服务的（全书反复出现的核心命题）。
- 用逆向思维认识设计：CSS 完胜 SVG 的武器正是"流"——SVG 图形强但文字排版弱，被 CSS 压制十年；理解一个技术的胜出原因，就是理解它的核心机制。
- 破坏流 ≠ 脱离流：float/absolute 等特殊布局手段是对流的破坏与保护（ch6），认知上要"从流出发"。

## Anti-patterns
- **用逻辑语言的学习方式学 CSS**：期望像编程语言一样从规则推导结果——CSS 无逻辑，看重具象与联系，会学成"干巴巴的属性"。
- **把"自适应布局"等同于"流体布局"**：前者是统称，后者仅指基于"流"特性的布局。

## Key Takeaways
1. 一切布局问题的出发点是"流"：先想清元素在流中本来会在哪里，再考虑破坏或保护。
2. CSS2.1 是为图文展示设计的世界——属性的行为差异几乎都能从这个设计初衷找到解释。
3. 书中所有行为基线是 IE8+；`<table>` 与 CSS3 另成世界，不套用"流"的心智模型。
