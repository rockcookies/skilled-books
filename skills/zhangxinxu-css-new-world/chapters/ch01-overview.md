# Chapter 1: 概述

## Core Idea
CSS3 已解体为模块化的"CSS 新世界"——没有 CSS4；新特性按当下 Web 场景设计，语法更明确、理解更容易，但记忆成本更高（本书覆盖 100+ 新特性）。

## Frameworks Introduced
- **CSS 新特性四方向**（全书框架）：① 更复杂、更具弹性的布局（flex/grid）；② 更丰富的视觉表现（圆角/阴影/动画/渐变）；③ 更多样的浏览设备支持（媒体查询/env()）；④ 开发者自定义能力（Houdini）。
- **语法更简单、理解更容易、记忆更昂贵**：CSS2.1 语法简单但理解难（基线等英语排版概念 + 属性用在远离设计本意的场景）；新特性分工明确（布局属性管布局、视觉属性管视觉），记住语法就不会有意外渲染——代价是属性数量暴增（仅 grid 就 27 个属性）。
- **模块化（Beijing doctrine）**：CSS 拆成独立模块各自标准化（选择器已 Level 4、弹性布局还是 Level 1），浏览器厂商可提前支持草案特性（env() 草案 2018 年制定、一年内移动端可用）。弊端是设计冗余（三布局对齐/间隙属性各自为政，后以 gap 统一）。
- **新特性因场景而生**：env() 源于 iPhone X 刘海；Multi-column 规范 1999 年制定（比 flex 早 10 年）——同为图文排版服务。

## Key Concepts
- 本书定位：《CSS世界》（CSS2.1）的续作，覆盖 CSS2.1 之后的特性；与《CSS选择器世界》构成 CSS 语言完整面貌。
- 术语约定（全书统一）：Edge = Edge12~18；现代浏览器 = Chrome/Safari/Firefox/Opera/Chromium Edge；IE9+ = IE9 及以上 + 全部 Edge + 现代浏览器。

## Mental Models
- "为什么会有这个属性、为什么这样设计"→ 回到它诞生的具体 Web 场景（设备、需求）找答案。
- 学新特性先看模块与数据类型（见 ch02），不必逐个记忆属性值。

## Key Takeaways
1. 没有 CSS4，"CSS3"也已名存实亡——现在是模块化标准化的时代。
2. 四方向分类是全书导航：布局、视觉、设备适配、自定义。
3. 新特性学习 = 低理解成本 × 高记忆成本，用数据类型和模块思维对冲。
